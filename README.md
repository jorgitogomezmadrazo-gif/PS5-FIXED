# Game Hub

`index.html` is the whole hub (one file). `sw.js` + `scramjet/` + `controller/` are the Scramjet proxy files it uses for linked games.

## Put it on GitHub and run it (GitHub Pages)
1. Create a new GitHub repository and upload **everything in this folder** (keep the `.github` folder).
2. Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Push/upload to `main`. The "Deploy Game Hub" action downloads the official Scramjet files and publishes the site.
   Your hub opens at `https://<you>.github.io/<repo>/`.
4. Open `config.js`, set `wisp` to your Wisp server (`wss://.../wisp/`), commit. Without a Wisp server the proxy toggle can't connect;
   the hub then loads links directly instead.

## Run it on your own computer
```
npm install
npm run fetch-scramjet
npx serve .        # or any static server; http://localhost works for service workers
```

## About jsDelivr
jsDelivr is a file CDN, not a website host: as far as I know it serves `.html` as plain text and a service worker must come from the
same origin as the page, so the hub itself (and the proxy) can't run from a `cdn.jsdelivr.net` link. Use GitHub Pages (above).
jsDelivr is fine for the hub's other files — games, covers and music are already loaded from it.

## Troubleshooting: "couldn't load scramjet/scramjet.js"
`scramjet/` and `controller/` are **not** in the repo on purpose. They are generated by `npm run fetch-scramjet`,
which the GitHub Action runs on every push. The error means those folders don't exist on the site you opened. Check, in order:
1. **Repo Settings → Pages → Source must be "GitHub Actions"** (not "Deploy from a branch"; a branch deploy publishes the repo as-is, with no `scramjet/` folder).
2. **`.github/workflows/pages.yml` must be in the repo.** Hidden folders are often skipped by drag-and-drop uploads.
3. **Repo → Actions tab:** the latest "Deploy Game Hub" run must be green. If it's red, open it; the "Run npm run fetch-scramjet" step now prints exactly which file is missing.
4. Open `https://<you>.github.io/<repo>/scramjet/scramjet.js` in any browser. If that 404s, the deploy didn't include it.
5. Opening `index.html` as a file or from a plain static host won't work either: run `npm install && npm run fetch-scramjet` first,
   then serve the folder over `http://localhost` or `https://`.

If you can't use Actions, run the two commands locally, delete the `scramjet/` and `controller/` lines from `.gitignore`, and commit those folders.
